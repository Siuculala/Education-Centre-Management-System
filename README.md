# Education-Centre-Management-System
A C# Windows Forms application for managing education centre records. 

## Features

- Add new records
- View all records
- Edit existing records
- Delete records
- Manage Teacher, Administration and Student records
- Validate user input

## Technologies

- C#
- .NET
- Windows Forms
- Object-Oriented Programming
- CRUD Operations

## Project Structure

- `Source/` contains the application source code
- `WinFormsApp.slnx` opens the solution in Visual Studio

## How to Run

1. Download the repository
2. Open `WinFormsApp.slnx` in Visual Studio
3. Build and run the application
